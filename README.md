# US Statutes PDF to USLM XML Pipeline

This repository contains a high-fidelity pipeline for accurately converting United States Statutes at Large from PDF into United States Legislative Markup (USLM) XML. It is designed to ensure no loss, distortion, or errors in text and structural conversion, leveraging the open-source [Docling](https://github.com/DS4SD/docling) library.

## Architecture

The project consists of three main modules:

1. **Downloader Module**: Interfaces with the GovInfo API to collect statute PDFs and ground truth XMLs at the granule level. It stores associated metadata (PL number, page numbers, dates, volume) into a PostgreSQL database.
2. **Pipeline Module**: Converts PDFs into the high-fidelity `DocLang` JSON intermediate format using Docling, and then transforms that structured output into compliant USLM XML.
3. **Benchmark Module**: Evaluates the PDF-to-XML conversion quality by comparing the pipeline's generated XML against GovInfo's natively published XML for post-2012 statutes. It utilizes an LLM (Claude 3 Opus) as a Vision-Language Model (VLM) judge to grade the conversion (0-100 score).

## Prerequisites

- **Docker & Docker Compose**: Used to run the PostgreSQL database and isolated Python environment.
- **Anthropic API Key**: Required for the Benchmark VLM judge.
- **GovInfo API Key**: Required to fetch the statutes.

## Setup Instructions

1. **Environment Variables**:
   Copy the example environment file and add your Anthropic API key.
   ```bash
   cp .env.example .env
   # Edit .env and insert your ANTHROPIC_API_KEY
   ```

2. **Start the Infrastructure**:
   Build and start the Docker containers. The `app` container installs all Python dependencies (managed by `uv`) including `docling`, `OpenCV`, and `Tesseract`.
   ```bash
   docker compose up -d --build
   ```

## Usage

You can run the modules by executing the Python scripts inside the running Docker `app` container.

### 1. Download Test Data
Fetch post-2012 statutes (Public Laws starting from the 113th Congress/Volume 127) directly from GovInfo. This will populate the `data/pdfs/` and `data/xmls/` directories and insert metadata into Postgres.

```bash
docker compose exec app python -m downloader.fetch
```

### 2. Run the Benchmark & Pipeline
Once the PDFs and ground-truth XMLs are downloaded, you can run the benchmark. This script will:
- Convert the PDFs to DocLang JSON.
- Transform the DocLang JSON to USLM XML.
- Send both the generated XML and ground-truth XML to Claude 3 Opus for evaluation.

```bash
docker compose exec app python -m benchmark.evaluate
```

## Database Schema

The pipeline uses PostgreSQL to maintain a strict audit trail:
- **`statutes`**: Stores the metadata for every fetched law (Congress, PL Number, Enactment Date).
- **`conversions`**: Tracks the conversion runs (tool used, file paths, success/error status).
- **`benchmarks`**: Stores the 0-100 fidelity scores and reasoning generated by the VLM judge.
